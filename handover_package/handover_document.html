1. Project Scope & Architecture Overview

The Annai Tuition Centre web platform has been redesigned into a modern educational web application tailored specifically for students and parents in Trichy. The application emphasizes trust, academic credibility, mobile responsiveness, and high conversion through direct WhatsApp & phone contact channels.

Core Technology Stack

  • Frontend Engine: React 18 single-page application built with modern functional components and hooks.
  • Build System: Vite 6 bundler for rapid page load times and optimized code splitting.
  • Routing System: React Router DOM v7 providing seamless page transitions without page reloads.
  • Design Theme: Royal Sapphire Navy (#071536) with Golden Warm Accents (#f5b82e). WCAG AA contrast compliant with zero unstyled white containers.
  • Hosting Infrastructure: Vercel Global Edge Network with automated continuous integration (CI/CD) and free SSL/TLS certificate.

3. Access & Ownership Transfer Instructions

IMPORTANT SECURITY DIRECTIVE (பாதுகாப்பு நெறிமுறை):
Passwords are NEVER written in plaintext documents. True ownership and administrative access are granted securely through direct account transfer and administrative invitation on GitHub and Vercel.

Step 1: Vercel Cloud Hosting Ownership Transfer

Vercel hosts the live production website. To transfer complete administrative control to the client:

  1. The client signs up for a free Vercel account at https://vercel.com/signup using the official tuition email (annaituitioncentre@gmail.com).
  2. In the developer Vercel Dashboard, navigate to Project Settings → Members.
  3. Invite annaituitioncentre@gmail.com as an Owner / Admin.
  4. The client accepts the invitation from their email. The project can also be transferred completely to the client's team under Project Settings → Transfer Project.

Step 2: GitHub Source Code Repository Transfer

The entire source code is maintained on GitHub under Git version control:

  1. The client creates or shares their GitHub username or email (e.g. annaituitioncentre).
  2. In the GitHub repository settings (Nisanth32/annai-tuition-centre), click on Collaborators → Add people and grant Admin access.
  3. Alternatively, under Settings → Danger Zone → Transfer Ownership, the entire repository can be permanently transferred to the client's GitHub account.

Step 3: Connecting a Custom Domain Name (e.g. annaituitioncentre.com)

When the client purchases or points their custom domain name:

  1. Go to Vercel Dashboard → Select annai-tuition-centre → Settings → Domains.
  2. Enter the desired domain (e.g., annaituitioncentre.com or .in) and click Add.
  3. Vercel will display two DNS records to configure at the domain registrar (GoDaddy, Hostinger, Namecheap):
    • A Record: Name @ → Value 76.76.21.21
    • CNAME Record: Name www → Value cname.vercel-dns.com
  4. Within minutes, Vercel verifies ownership and automatically issues a free, auto-renewing SSL certificate.

4. Ongoing Maintenance & Backup Protocol

  • Automatic Git Backups: Every code modification is tracked with complete history in Git commits. Any version can be restored at any time in seconds.
  • No Server Maintenance Required: The website is deployed as a static-optimized SPA on Vercel's serverless CDN, meaning zero server crashes, zero maintenance fees, and 99.99% uptime.
  • Updating Student Results / Toppers: Whenever new board results are released, new marks and student photos can be added to src/App.jsx and deployed instantly with git push.
